@@I What is AngularJS?
AngularJS is a free, open-source **JavaScript framework made by Google** for building dynamic **single-page web applications**. It adds extra features to HTML, such as directives (`ng-model`, `ng-repeat`) and two-way data binding.

@@I The full form of NPM is [[Node Package Manager]].
NPM installs and manages the packages (ready-made code libraries) that Node.js and Angular projects need.

@@I AngularJS provides Reusable components. True/False?
@@TF True
Directives and components are written once and can be used again anywhere in the app, like one `<student-card>` used on many pages.

@@I The full form of SPA is [[Single Page Application]].
An SPA loads one HTML page and then changes only the needed part of it, without reloading the whole page (Gmail works like this).

@@I What is CLI and when to use it in Angular?
**Angular CLI** (Command Line Interface) is a tool that we run in the terminal to create, run and build Angular apps. Its command is `ng`, and we install it with `npm install -g @angular/cli`.

We use it when we want to:

- **create** a new project: `ng new my-app`
- **generate** parts of the app: `ng generate component home` (also service, module, pipe)
- **run** the app on a local server: `ng serve`
- **build** the final app for hosting: `ng build`, or **test** it: `ng test`

@@I Differentiate AngularJS v/s Angular.
| Point | AngularJS | Angular |
|---|---|---|
| Version | 1.x (released 2010) | 2 and above (from 2016) |
| Language | JavaScript | TypeScript |
| Structure | MVC with controllers and `$scope` | Component-based |
| Binding syntax | `ng-bind`, `ng-model` | `[property]`, `(event)`, `[(ngModel)]` |
| Tools and speed | No official CLI, slower | Angular CLI, faster and mobile friendly |

@@I How do you create your first Angular Project? Give steps.
**Step 1 – Install Node.js.** Download the LTS version from nodejs.org. It installs npm too. Check with `node -v` and `npm -v`.

**Step 2 – Install Angular CLI** globally, then check it.

**Step 3 – Create the project** with `ng new`. The CLI asks a few questions (stylesheet type, routing). Press Enter to accept the defaults.

**Step 4 – Run the project.** Go into the folder and start the development server.

```bash
npm install -g @angular/cli      # step 2
ng version                       # check the CLI

ng new my-first-app              # step 3
cd my-first-app                  # step 4
ng serve --open                  # opens http://localhost:4200
```

**Step 5 – Edit the app.** Open `src/app/app.component.html` (called `app.html` in the newest versions), change the text and save. The browser reloads by itself and shows the change.

@@I What is Component? How many Components are there in angularJS?
A **component** is a reusable building block of the screen. A header, a menu or a student list can each be a component. Every component has three parts:

- **Template** – the HTML that is shown
- **Class** – the TypeScript code (data and functions)
- **Metadata** – the `@Component` decorator that joins them (selector, template, styles)

**How many?** There is no fixed number. An app can have as many components as it needs. Every app starts with one root component (`AppComponent`), and all other components sit inside it like a tree. The command `ng generate component hello` creates 4 files for one component: `.ts`, `.html`, `.css` and `.spec.ts` (test).

```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-hello',                  // used in HTML as <app-hello>
  template: '<h2>Hello {{ name }}</h2>'
})
export class HelloComponent {
  name = 'Priya';
}
```

In AngularJS (version 1.5 and above), a component is made with `app.component('hello', { template: '...', controller: function () {...} })`.

@@I How to install Node and NPM on windows?
**Node.js** lets us run JavaScript outside the browser, and **NPM** (Node Package Manager) installs libraries. NPM comes inside the Node.js installer, so one setup installs both. Angular needs both of them.

#### Steps to install

1. Open **nodejs.org** and download the **LTS** (Long Term Support) version, "Windows Installer (.msi)", 64-bit.
2. Double-click the downloaded `.msi` file and click **Next**.
3. Accept the licence agreement and click **Next**.
4. Keep the default install folder `C:\Program Files\nodejs\`.
5. On the **Custom Setup** screen, keep **npm package manager** and **Add to PATH** selected.
6. Click **Install**, allow admin permission, then click **Finish**.

#### Check the installation

Open a new **Command Prompt** and type:

```bash
node -v        # shows the Node version, for example v22.11.0
npm -v         # shows the npm version, for example 10.9.0
```

#### Test with a small program

Create a file `hello.js` that contains `console.log("Node is working");` and run it with `node hello.js`. If the message prints, Node is ready.

> **Tip:** If you see "node is not recognized", close and reopen Command Prompt, or restart the PC so the new PATH is loaded. To update npm later, run `npm install -g npm@latest`.

@@I Explain MVC Framework.
**MVC** stands for **Model – View – Controller**. It is a design pattern that divides an application into three parts, so that the data, the screen and the logic are kept separate. AngularJS follows this pattern.

- **Model** – holds the **data** of the app. In AngularJS, data is stored on `$scope`.
- **View** – what the **user sees**: the HTML page with expressions like `{{ name }}`.
- **Controller** – the **logic** that connects Model and View. It reacts to user actions and updates the data. In AngularJS it is a JavaScript function attached with `ng-controller`.

#### Example in AngularJS

```html
<div ng-app="myApp" ng-controller="StudentCtrl">
  <p>Name: {{ student.name }}</p>                <!-- View -->
  <button ng-click="changeName()">Change</button>
</div>

<script>
  var app = angular.module('myApp', []);
  app.controller('StudentCtrl', function ($scope) {   // Controller
    $scope.student = { name: 'Riya' };                 // Model
    $scope.changeName = function () {
      $scope.student.name = 'Aman';                    // View updates by itself
    };
  });
</script>
```

#### Advantages of MVC

- **Separation of work:** design, data and logic stay in different places.
- **Easy to maintain:** a change in the view does not break the logic.
- **Easy to test:** controllers and models can be tested alone.
- **Teamwork:** designers and developers can work at the same time.
- **Reusable code:** one model can be shown in many views.

In short, MVC keeps an app organised, and AngularJS adds automatic data binding so the View and Model stay in sync.
