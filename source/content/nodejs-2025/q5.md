@@I What is the purpose of Express in a Node.js application?
**Express** is a **web framework built on top of Node.js**. Its purpose is to make building web servers and APIs **faster and simpler** than with the plain `http` module. It gives:

- easy **routing**, such as `app.get('/about', ...)`
- **middleware** for common jobs (reading form data, cookies, logging)
- helpers like `res.send()`, `res.json()` and `res.sendFile()`
- **static file** serving and **template engines**

```js
const express = require('express');
const app = express();
app.get('/', (req, res) => res.send('Hello Express'));
app.listen(3000);
```

@@I What is the use of res.sendFile()?
`res.sendFile(path)` **sends a file** (an HTML page, PDF or image) as the response. Express sets the **Content-Type** from the file extension. The path must be **absolute**, so we build it with `path.join(__dirname, ...)`. An optional callback reports errors, such as a missing file.

```js
const path = require('path');

app.get('/about', (req, res) => {
  res.sendFile(path.join(__dirname, 'views', 'about.html'));
});
```

@@I Describe how to handle file uploads in Express using multer.
**Multer** is a middleware for handling **`multipart/form-data`**, the format forms use to send files. It saves the uploaded file and puts its details in **`req.file`** (or `req.files` for many files), and the text fields in `req.body`.

1. Install it: `npm install multer`.
2. Set where and how files are saved with `multer.diskStorage()` (or simply `multer({ dest: 'uploads/' })`). Create the `uploads` folder first.
3. Make an HTML form with **`enctype="multipart/form-data"`** and a file input.
4. Add `upload.single('photo')` (one file) or `upload.array('photos', 5)` (several) to the route.
5. Read the file details from `req.file`.

```js
const express = require('express');
const multer = require('multer');
const app = express();

const storage = multer.diskStorage({
  destination: (req, file, cb) => cb(null, 'uploads/'),
  filename: (req, file, cb) => cb(null, Date.now() + '-' + file.originalname)
});
const upload = multer({ storage, limits: { fileSize: 2 * 1024 * 1024 } });   // max 2 MB

app.post('/upload', upload.single('photo'), (req, res) => {
  res.send(`Saved ${req.file.originalname} (${req.file.size} bytes)`);
});

app.listen(3000);
```

```html
<form action="/upload" method="post" enctype="multipart/form-data">
  <input type="file" name="photo">
  <button type="submit">Upload</button>
</form>
```

The input's `name` (`photo`) must match the name given to `upload.single()`.

@@I How to use express.static() to serve static files?
`express.static()` is a **built-in middleware** that serves files such as images, CSS, JavaScript and HTML **directly from a folder**.

1. Put the files in a folder, usually `public`.
2. Add the middleware with `app.use()`.
3. Open the files in the browser by their path **inside** the folder; the folder name is not part of the URL.

```tree
project/
├── app.js
└── public/
    ├── index.html
    ├── style.css
    └── images/logo.png
```

```js
const express = require('express');
const path = require('path');
const app = express();

app.use(express.static(path.join(__dirname, 'public')));
app.listen(3000);
```

Now `http://localhost:3000/` gives `index.html`, `/style.css` gives the CSS and `/images/logo.png` gives the picture. To add a prefix, write `app.use('/static', express.static('public'))`, which changes the URL to `/static/style.css`. Several folders can be added; Express checks them in order.

@@I What are templates in Express? Explain how to configure and use a template engine like EJS or Pug to render dynamic HTML pages.
A **template** is an HTML file with **placeholders and simple logic** (loops, if conditions). A **template engine** fills the placeholders with **real data on the server** and sends the finished HTML to the browser. This lets one file show different data for each user, such as a name or a list of products, without building HTML strings by hand.

#### Using EJS (Embedded JavaScript)

**Step 1 – Install:** `npm install ejs`

**Step 2 – Configure:** tell Express which engine to use. Templates are looked for in the `views` folder by default (change it with `app.set('views', folderPath)`).

**Step 3 – Render:** call `res.render(fileName, data)` in a route.

```js
const express = require('express');
const app = express();

app.set('view engine', 'ejs');                  // configure the engine

app.get('/', (req, res) => {
  res.render('index', {                         // uses views/index.ejs
    name: 'Riya',
    subjects: ['Node JS', 'Flutter', 'Angular']
  });
});

app.listen(3000);
```

**Step 4 – Write the template** `views/index.ejs`:

```ejs
<!DOCTYPE html>
<html>
<body>
  <h1>Welcome, <%= name %>!</h1>
  <ul>
    <% subjects.forEach(function (s) { %>
      <li><%= s %></li>
    <% }); %>
  </ul>
</body>
</html>
```

The browser receives normal HTML: a heading "Welcome, Riya!" and a list of the three subjects.

| EJS tag | Meaning |
|---|---|
| `<%= value %>` | Print a value (HTML is escaped, which is safe) |
| `<% code %>` | Run JavaScript such as `if` or loops; prints nothing |
| `<%- include('header') %>` | Insert another template (a partial) |

#### Using Pug instead

Install with `npm install pug`, set `app.set('view engine', 'pug')`, and call `res.render('index', {...})` the same way. Pug uses **indentation instead of closing tags**:

```pug
html
  body
    h1 Welcome, #{name}!
    ul
      each s in subjects
        li= s
```

| Point | EJS | Pug |
|---|---|---|
| Looks like | Normal HTML with `<% %>` tags | Short, indentation-based code |
| File extension | `.ejs` | `.pug` |
| Easy for beginners | Yes, if you know HTML | Needs learning the new syntax |

Templates keep the page design (HTML) separate from the server logic, so the code stays clean and pages become dynamic.

@@I Explain how routing works in Express, including route parameters, multiple callbacks, and chaining handlers.
**Routing** decides **which code runs for which URL and HTTP method**. A route is written as **`app.METHOD(path, handler)`**, where METHOD is `get`, `post`, `put` or `delete`. Express checks routes **from top to bottom** and runs the first one that matches.

#### 1. Basic routes

```js
app.get('/', (req, res) => res.send('Home page'));
app.post('/students', (req, res) => res.send('Student added'));
```

#### 2. Route parameters

Parts of the path that start with `:` capture values into **`req.params`**.

```js
app.get('/students/:id', (req, res) => {
  res.send('Student id: ' + req.params.id);       // /students/25  ->  Student id: 25
});
```

#### 3. Multiple callbacks

A route can have **more than one handler function**. Each one gets a third parameter, **`next`**; calling `next()` passes control to the next handler. This is useful for checks such as login before the real work.

```js
function checkLogin(req, res, next) {
  if (req.query.token === 'abc123') next();       // allowed: go to the next callback
  else res.status(401).send('Please log in');     // stop here
}

app.get('/profile', checkLogin, (req, res) => {
  res.send('Your profile');
});
// The callbacks can also be given as an array: app.get('/profile', [checkLogin, showProfile])
```

#### 4. Chaining route handlers

When one path needs several methods, **`app.route(path)`** lets us chain them **without repeating the path**.

```js
app.route('/books')
  .get((req, res) => res.send('List of books'))
  .post((req, res) => res.send('Book added'))
  .put((req, res) => res.send('Book updated'));
```

| Request | Output |
|---|---|
| `GET /students/25` | Student id: 25 |
| `GET /profile?token=abc123` | Your profile |
| `GET /profile` | 401 Please log in |
| `POST /books` | Book added |

#### 5. Modular routes with `express.Router()`

For big apps, routes are grouped in separate files with `express.Router()` and attached with `app.use('/students', studentRouter)`. Inside the router, `/:id` then means `/students/:id`.

So, routing in Express combines a **method**, a **path** (with optional parameters) and one or more **handlers**, which together decide how each request is answered.
