@@S B

@@I How does fs.writeFile() work in Node.js?
`fs.writeFile(file, data, [options], callback)` **writes data to a file asynchronously**.

- If the file **does not exist**, it is **created**.
- If the file **exists**, its old content is **replaced**.
- Node does not wait; the **callback** runs after writing and receives `err` if something failed.

```js
const fs = require('fs');
fs.writeFile('note.txt', 'Exam on Monday', 'utf8', (err) => {
  if (err) return console.log(err.message);
  console.log('Saved!');
});
```

@@I What is the purpose of the fs.unlink() method in Node.js?
`fs.unlink(path, callback)` is used to **delete a file** asynchronously. If the file does not exist, the callback receives an `ENOENT` error. The synchronous version is `fs.unlinkSync(path)`. It removes files only; folders are removed with `fs.rmdir()` or `fs.rm()`.

```js
const fs = require('fs');
fs.unlink('note.txt', (err) => {
  if (err) return console.log('Error:', err.message);
  console.log('File deleted');
});
```

@@S C

@@I Describe how the url module can help serve files in an HTTP server.
When the browser asks for a page, the address arrives in **`req.url`**, for example `/summer.html?lang=en`. The **url module splits this address**, so we can take just the **pathname** (`/summer.html`) and ignore the query string. We then turn the pathname into a **file name**, read that file with `fs`, and send it. If the file is missing, we send **404**.

```js
const http = require('http');
const fs = require('fs');
const url = require('url');

http.createServer((req, res) => {
  const q = url.parse(req.url, true);         // split the URL into parts
  const filename = '.' + q.pathname;           // /summer.html  ->  ./summer.html

  fs.readFile(filename, (err, data) => {
    if (err) {
      res.writeHead(404, { 'Content-Type': 'text/html' });
      return res.end('404 Not Found');
    }
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end(data);
  });
}).listen(8080);
```

Now `http://localhost:8080/summer.html` shows `summer.html`, and `/winter.html` shows `winter.html`, all with one piece of code. The same parsed object also gives query values through `q.query`.

@@I What is the difference between fs.writeFile() and fs.appendFile()?
| Point | `fs.writeFile()` | `fs.appendFile()` |
|---|---|---|
| Old content | **Replaced** (overwritten) | **Kept**; new data is added at the end |
| File missing | Creates the file | Creates the file |
| Used for | Saving fresh content, like a new report | Adding to a log, like a visitor list |
| Default flag | `'w'` | `'a'` |

```js
const fs = require('fs');

fs.writeFileSync('log.txt', 'Line 1\n');     // file: Line 1
fs.appendFileSync('log.txt', 'Line 2\n');    // file: Line 1, Line 2
fs.writeFileSync('log.txt', 'New start\n');  // file: New start (old lines gone)
```

@@S D

@@I Describe the various file operations supported by the fs module with examples.
The **`fs` (file system)** module lets Node.js work with files and folders on the computer. We load it with `const fs = require('fs');`. Every method comes in three forms: **callback** (`fs.readFile`), **synchronous** (`fs.readFileSync`) and **promise** (`fs.promises.readFile`).

| Operation | Method | What it does |
|---|---|---|
| Create / write | `fs.writeFile()` | Creates a file or replaces its content |
| Read | `fs.readFile()` | Reads the whole file |
| Append | `fs.appendFile()` | Adds data at the end of a file |
| Open | `fs.open()` | Opens a file with a flag (`r`, `w`, `a`) |
| Rename / move | `fs.rename()` | Changes a file's name or folder |
| Delete | `fs.unlink()` | Deletes a file |
| File details | `fs.stat()` | Size, dates, file or folder |
| Make folder | `fs.mkdir()` | Creates a directory |
| List folder | `fs.readdir()` | Gives the names inside a directory |
| Remove folder | `fs.rmdir()` / `fs.rm()` | Deletes a directory |

#### Example: all operations in one program

```js
const fs = require('fs').promises;

async function demo() {
  await fs.writeFile('notes.txt', 'Hello');                // create / write
  await fs.appendFile('notes.txt', ' World');              // append
  const text = await fs.readFile('notes.txt', 'utf8');     // read
  console.log('Content:', text);

  await fs.rename('notes.txt', 'myNotes.txt');             // rename
  const info = await fs.stat('myNotes.txt');               // details
  console.log('Size:', info.size, 'bytes');

  await fs.mkdir('backup', { recursive: true });           // make folder
  console.log('Folder:', await fs.readdir('.'));           // list folder

  await fs.unlink('myNotes.txt');                          // delete file
  await fs.rmdir('backup');                                // remove folder
  console.log('Cleaned up');
}

demo().catch((err) => console.log('Error:', err.message));
```

```output
Content: Hello World
Size: 11 bytes
Folder: [ 'app.js', 'backup', 'myNotes.txt' ]
Cleaned up
```

#### The same read in all three forms

```js
fs.readFile('a.txt', 'utf8', (err, data) => console.log(data));   // callback
const data = fs.readFileSync('a.txt', 'utf8');                    // synchronous
const data2 = await fs.promises.readFile('a.txt', 'utf8');        // promise (inside async)
```

(In this small snippet `fs` is the normal `require('fs')` module.)

**Tip:** use the asynchronous forms in servers, so one slow file does not block other users; always handle the error (for example `ENOENT` when a file is missing).

@@I Explain how to handle HTTP requests in Node.js to serve files based on URLs.

#### Steps

1. Create the server with `http.createServer()`.
2. Take the **pathname** from `req.url` (using the `URL` class).
3. If the pathname is `/`, use `/index.html` as the home page.
4. Build the full file path with `path.join(__dirname, 'public', pathname)`.
5. Pick the **Content-Type** from the file extension (`.html`, `.css`, `.png` ...).
6. Read the file with `fs.readFile()`. If it fails, send **404**; otherwise send **200** with the file.

```tree
project/
├── server.js
└── public/
    ├── index.html
    ├── about.html
    └── css/style.css
```

```js
const http = require('http');
const fs = require('fs');
const path = require('path');

const root = path.join(__dirname, 'public');
const types = {
  '.html': 'text/html', '.css': 'text/css', '.js': 'text/javascript',
  '.png': 'image/png', '.jpg': 'image/jpeg', '.json': 'application/json'
};

http.createServer((req, res) => {
  const { pathname } = new URL(req.url, 'http://localhost');     // step 2
  const page = pathname === '/' ? '/index.html' : pathname;        // step 3
  const filePath = path.join(root, page);                           // step 4

  if (!filePath.startsWith(root)) {                                 // block "../" tricks
    res.writeHead(403);
    return res.end('Forbidden');
  }

  const type = types[path.extname(filePath)] || 'application/octet-stream';   // step 5

  fs.readFile(filePath, (err, data) => {                            // step 6
    if (err) {
      res.writeHead(404, { 'Content-Type': 'text/html' });
      return res.end('<h1>404 - File not found</h1>');
    }
    res.writeHead(200, { 'Content-Type': type });
    res.end(data);
  });
}).listen(3000, () => console.log('Server running at http://localhost:3000'));
```

| URL | File sent | Status |
|---|---|---|
| `/` | `public/index.html` | 200 |
| `/about.html` | `public/about.html` | 200 |
| `/css/style.css` | `public/css/style.css` (as `text/css`) | 200 |
| `/contact.html` | (does not exist) | 404 |

The correct **Content-Type** matters: without it the browser may show CSS or images as plain text. In real projects, Express does all of this with one line: `app.use(express.static('public'))`.
