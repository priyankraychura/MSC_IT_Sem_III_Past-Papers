@@I What is buffer ?
A **Buffer** is a temporary memory area that stores **raw binary data (bytes)**. Node uses buffers for files, network streams and images, for example `Buffer.from('Hi')` gives `<Buffer 48 69>`.

@@I List out NodeJS modules.
Core modules: `http`, `fs`, `path`, `url`, `querystring`, `os`, `events`, `util`, `stream`, `crypto`. (Modules are of three types: core, local and third-party.)

@@I URL stands for [[Uniform Resource Locator]].
It is the address of a resource on the web, like `https://example.com/about`.

@@I The Query String module used to convert query string into JSON object. (True/False)
@@TF True
`querystring.parse('name=Ravi&age=21')` gives the object `{ name: 'Ravi', age: '21' }`.

@@S B

@@I Explain in brief : NPM
**NPM (Node Package Manager)** is the default package manager of Node.js and is installed along with it. It has two parts: an online **registry** (npmjs.com) with millions of free packages, and a **command-line tool** to install and manage them.

- `npm init` – creates `package.json`
- `npm install express` – installs a package into `node_modules`
- `npm install -g nodemon` – installs a tool globally
- `npm uninstall express`, `npm update`, `npm list`

The list of installed packages is saved in `package.json`, so anyone can reinstall them with `npm install`.

@@I How to install package globally ?
We add the **`-g`** (global) flag: **`npm install -g <package-name>`**. A global package is installed in a system folder, not inside the project, so its command works **from any folder**. It is used for tools such as `nodemon`, `typescript` and `@angular/cli`.

```bash
npm install -g nodemon      # install globally
nodemon --version           # works from any folder
npm list -g --depth=0       # see all global packages
npm uninstall -g nodemon    # remove it
```

On Linux or macOS you may need to add `sudo` in front.

@@S C

@@I Explain primitive datatypes.
JavaScript, and so Node.js, has **7 primitive data types**. A primitive holds **one simple value**; it cannot be changed (immutable) and is copied by value.

| Type | Example | Meaning |
|---|---|---|
| String | `'Ravi'` | Text |
| Number | `25`, `3.14` | Whole and decimal numbers |
| BigInt | `123n` | Very large whole numbers |
| Boolean | `true`, `false` | Yes or no |
| Undefined | `let x;` | Declared but no value yet |
| Null | `let y = null;` | Empty on purpose |
| Symbol | `Symbol('id')` | A unique identifier |

```js
console.log(typeof 'Ravi');        // string
console.log(typeof 25);            // number
console.log(typeof 123n);          // bigint
console.log(typeof true);          // boolean
console.log(typeof undefined);     // undefined
console.log(typeof null);          // object  (an old JavaScript quirk)
console.log(typeof Symbol('id'));  // symbol
```

@@I Explain local module.
A **local module** is a module that **we create ourselves** inside our project. It is not built into Node and not downloaded from npm. Local modules let us split code into small files and reuse it.

1. Create a file, for example `calc.js`, and write functions in it.
2. **Export** them with `module.exports`.
3. **Import** the file in another file with `require('./calc')`. The path starts with `./`.

```js
// calc.js  (local module)
function add(a, b) { return a + b; }
function sub(a, b) { return a - b; }
module.exports = { add, sub };
```

```js
// app.js
const calc = require('./calc');
console.log(calc.add(10, 5));   // 15
console.log(calc.sub(10, 5));   // 5
```

@@S D

@@I Explain Query String module.
The **`querystring`** module is a **built-in (core) module** used to work with the **query string** of a URL, which is the part after `?`, like `name=Ravi&age=21`. It can turn a query string into an object, and an object back into a query string.

We load it with `const querystring = require('querystring');`

| Method | Use |
|---|---|
| `parse()` (also `decode()`) | Query string → object |
| `stringify()` (also `encode()`) | Object → query string |
| `escape()` | Encodes special characters (space becomes `%20`) |
| `unescape()` | Decodes them back |

#### Example

```js
const querystring = require('querystring');

// 1. parse: string to object
const obj = querystring.parse('name=Ravi&age=21&city=Rajkot');
console.log(JSON.stringify(obj));   // {"name":"Ravi","age":"21","city":"Rajkot"}
console.log(obj.name);              // Ravi

// 2. stringify: object to string
console.log(querystring.stringify({ course: 'MSc IT', sem: 3 }));   // course=MSc%20IT&sem=3

// 3. custom separators: ';' between pairs and ':' between key and value
console.log(querystring.parse('name:Ravi;age:21', ';', ':').name);   // Ravi

// 4. escape and unescape
console.log(querystring.escape('a b&c'));         // a%20b%26c
console.log(querystring.unescape('a%20b%26c'));   // a b&c
```

#### Using it in a web server

```js
const http = require('http');
const querystring = require('querystring');

http.createServer((req, res) => {
  const q = querystring.parse(req.url.split('?')[1] || '');
  res.end('Hello ' + (q.name || 'guest'));
}).listen(3000);
// http://localhost:3000/?name=Ravi  shows  Hello Ravi
```

#### Points to remember

- All values come back as **strings** (`age` is `'21'`, not `21`).
- If a key repeats, its values come back as an array.
- `querystring` is an older (legacy) module; new code can also use `URLSearchParams`.

#### 1. Modern way: the `URL` class

```js
const myUrl = new URL('https://example.com:8080/students/list?year=2024&sem=3#top');

console.log(myUrl.protocol);                  // https:
console.log(myUrl.host);                      // example.com:8080
console.log(myUrl.hostname);                  // example.com
console.log(myUrl.port);                      // 8080
console.log(myUrl.pathname);                  // /students/list
console.log(myUrl.search);                    // ?year=2024&sem=3
console.log(myUrl.searchParams.get('year'));  // 2024
console.log(myUrl.hash);                      // #top
```

#### 2. Older way: `url.parse()`

```js
const url = require('url');
const q = url.parse('http://localhost:3000/default.htm?year=2024&month=march', true);

console.log(q.host);        // localhost:3000
console.log(q.pathname);    // /default.htm
console.log(q.search);      // ?year=2024&month=march
console.log(q.query.month); // march   (true = turn the query into an object)
```

#### Uses of the URL module

- In a web server, read `req.url` to find which **page** (pathname) the user wants.
- Read **form values** sent in the query string.
- Build URLs from parts with `url.format()` or by setting properties of a `URL` object.

So the URL module saves us from cutting the address string by hand and makes routing and reading data simple.
