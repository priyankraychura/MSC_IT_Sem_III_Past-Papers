@@S B

@@I Define : fs.renameSync()
`fs.renameSync(oldPath, newPath)` **renames a file, or moves it to another folder, synchronously**. "Sync" means Node **waits** until renaming is finished before running the next line. It throws an error if the file does not exist.

```js
const fs = require('fs');

try {
  fs.renameSync('old.txt', 'new.txt');
  console.log('File renamed');
} catch (err) {
  console.log('Error:', err.message);
}
```

@@I List out modes for opening a file.
The mode (called a **flag**) is passed to `fs.open()`, for example `fs.open('demo.txt', 'w', callback)`.

| Flag | Meaning |
|---|---|
| `r` | Read only. Error if the file does not exist (default). |
| `r+` | Read and write. Error if the file does not exist. |
| `w` | Write only. Creates the file, or empties it if it exists. |
| `w+` | Read and write. Creates or empties the file. |
| `wx` | Like `w`, but fails if the file already exists. |
| `a` | Append (add at the end). Creates the file if missing. |
| `a+` | Read and append. Creates the file if missing. |
| `ax` | Like `a`, but fails if the file already exists. |

@@I Write a code to write a file.
```js
const fs = require('fs');

// Asynchronous: Node does not wait, the callback runs when writing is done
fs.writeFile('student.txt', 'Name: Riya\nCourse: MSc IT', (err) => {
  if (err) {
    console.log('Error:', err.message);
    return;
  }
  console.log('File written successfully');
});
```

```output
File written successfully
```

- `fs.writeFile(file, data, callback)` **creates** the file if it does not exist, and **replaces** the old content if it does.
- The callback receives an `err` object if something goes wrong (for example, no permission).
- The synchronous version is `fs.writeFileSync('student.txt', 'Hello');`, which blocks until it finishes.

@@I Write a code to delete a file.
```js
const fs = require('fs');

fs.unlink('student.txt', (err) => {
  if (err) {
    console.log('Could not delete:', err.message);
    return;
  }
  console.log('File deleted successfully');
});
```

```output
File deleted successfully
```

- `fs.unlink(path, callback)` deletes the file at that path.
- If the file is missing, `err.message` is `ENOENT: no such file or directory, unlink 'student.txt'`.
- Synchronous way with a check first:

```js
if (fs.existsSync('student.txt')) {
  fs.unlinkSync('student.txt');
  console.log('Deleted');
}
```

@@I How to read content in file ? Explain with example.
The **`fs` (file system)** module gives several ways to read a file:

1. **`fs.readFile()`** – asynchronous, with a callback. Best choice in most programs.
2. **`fs.readFileSync()`** – synchronous; Node waits until the file is read.
3. **`fs.promises.readFile()`** – asynchronous, used with `async` / `await`.
4. **`fs.createReadStream()`** – reads **big files in small pieces** (chunks).

**Syntax:** `fs.readFile(path, encoding, callback(err, data))`. If we do not give the encoding `'utf8'`, `data` comes back as a Buffer (raw bytes) instead of text.

#### Example

Suppose `data.txt` contains the line `Hello from the file!`

```js
const fs = require('fs');

// 1. Asynchronous read
fs.readFile('data.txt', 'utf8', (err, data) => {
  if (err) return console.log('Error:', err.message);
  console.log('Async:', data);
});

// 2. Synchronous read
const text = fs.readFileSync('data.txt', 'utf8');
console.log('Sync:', text);
```

```output
Sync: Hello from the file!
Async: Hello from the file!
```

The **sync** line prints first, because the async callback runs only after the file has been read in the background.

#### With async / await

```js
const fsp = require('fs').promises;

async function show() {
  try {
    const data = await fsp.readFile('data.txt', 'utf8');
    console.log(data);
  } catch (err) {
    console.log('Error:', err.message);
  }
}
show();
```

#### For a large file: stream

```js
const stream = fs.createReadStream('big.log', 'utf8');
stream.on('data', (chunk) => console.log('Got', chunk.length, 'characters'));
stream.on('end', () => console.log('Finished reading'));
```

#### Points to remember

- Always handle the error; a missing file gives the error code `ENOENT`.
- Use `'utf8'` to get text instead of a Buffer.
- In servers, prefer the asynchronous methods so other users are not kept waiting.

@@I Write a code to handle http request for Web Server.
A web server receives a **request** from the browser and sends back a **response**. Node's built-in **`http`** module lets us build one and decide what to send for each URL.

```js
const http = require('http');

const server = http.createServer((req, res) => {
  console.log(req.method, req.url);                     // log every request

  if (req.method === 'GET' && req.url === '/') {
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end('<h1>Home Page</h1>');

  } else if (req.method === 'GET' && req.url === '/about') {
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end('<h1>About Us</h1>');

  } else if (req.method === 'GET' && req.url === '/api/students') {
    res.writeHead(200, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify([{ id: 1, name: 'Riya' }, { id: 2, name: 'Aman' }]));

  } else if (req.method === 'POST' && req.url === '/submit') {
    let body = '';
    req.on('data', (chunk) => body += chunk);           // collect sent data
    req.on('end', () => {
      res.writeHead(200, { 'Content-Type': 'text/plain' });
      res.end('Received: ' + body);
    });

  } else {
    res.writeHead(404, { 'Content-Type': 'text/html' });
    res.end('<h1>404 - Page not found</h1>');
  }
});

server.listen(3000, () => console.log('Server running at http://localhost:3000'));
```

#### How it works

- `require('http')` loads the built-in module.
- `http.createServer(callback)` creates the server. The callback runs for **every request** and gets two objects: **`req`** (the request: `url`, `method`, `headers`) and **`res`** (the response we send).
- `res.writeHead(status, headers)` sets the status code (200 OK, 404 Not Found) and the content type.
- `res.end(data)` sends the data and finishes the response.
- `req.on('data')` and `req.on('end')` collect the body of a POST request.
- `server.listen(3000)` starts the server on port 3000.

| URL in browser | Response |
|---|---|
| `http://localhost:3000/` | Home Page |
| `http://localhost:3000/about` | About Us |
| `http://localhost:3000/api/students` | JSON list of students |
| `http://localhost:3000/xyz` | 404 - Page not found |
