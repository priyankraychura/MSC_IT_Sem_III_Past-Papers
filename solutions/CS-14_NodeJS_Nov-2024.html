What is REPL ?

REPL stands for Read – Eval – Print – Loop. It is Node's interactive shell, where we type JavaScript and see the result at once.

  • Read – reads what we type
  • Eval – runs (evaluates) it

  • Loop – waits for the next input

We start it by typing node in the terminal. Useful commands: .help, .editor, .save, .load, and .exit (or Ctrl+C twice).

How to create Node file with JavaScript ?

A Node file is a plain JavaScript file with the .js extension that we run with the node command instead of a browser.

Steps

  1. Install Node.js from nodejs.org and check it with node -v.
  2. Make a project folder and open it in the terminal.
  3. (Optional) Create package.json with npm init -y.
  4. Create a file such as app.js in VS Code or Notepad.
  5. Write JavaScript code in it and save.
  6. Run it with node app.js and see the output in the terminal.

Explain Node JS process model.

The process model explains how Node.js handles many client requests at the same time. Node.js uses a single-threaded, event-driven, non-blocking I/O model.

Traditional web server model

Servers like Apache or IIS (classic setup) create one thread for each request. While a thread waits for a file or database, it sits idle (it is blocked). Thousands of users need thousands of threads, which uses a lot of memory.

Node.js model

  1. Clients send requests, and Node places them in the event queue.
  2. The event loop, running on one main thread, picks the requests one by one.
  3. If a request is quick (no waiting), it is processed and the response is sent at once.
  4. If a request needs slow I/O (reading a file, a database query, a network call), Node hands it to the thread pool (managed by the libuv library) and moves on to the next request without waiting.
  5. When the slow work finishes, its callback goes back to the queue, and the event loop runs it and sends the response.
JavaScript
const fs = require('fs');

console.log('1. Start');
fs.readFile('data.txt', 'utf8', (err, data) => {
  console.log('3. File reading finished');     // callback runs later
});
console.log('2. Next task runs without waiting');
Output
1. Start
2. Next task runs without waiting
3. File reading finished

Advantages

  • One thread can serve thousands of connections using little memory.
  • Very fast for I/O-heavy apps such as chat, APIs and streaming.

Limitation

CPU-heavy work (image processing, huge calculations) keeps the single thread busy and slows every user. For such work, Node offers worker threads or child processes.

Explain Query String module.

The querystring module is a built-in (core) module used to work with the query string of a URL, which is the part after ?, like name=Ravi&age=21. It can turn a query string into an object, and an object back into a query string.

We load it with const querystring = require('querystring');

Method Use
parse() (also decode()) Query string → object
stringify() (also encode()) Object → query string
escape() Encodes special characters (space becomes %20)
unescape() Decodes them back

Example

JavaScript
const querystring = require('querystring');

// 1. parse: string to object
const obj = querystring.parse('name=Ravi&age=21&city=Rajkot');
console.log(JSON.stringify(obj));   // {"name":"Ravi","age":"21","city":"Rajkot"}
console.log(obj.name);              // Ravi

// 2. stringify: object to string
console.log(querystring.stringify({ course: 'MSc IT', sem: 3 }));   // course=MSc%20IT&sem=3

// 3. custom separators: ';' between pairs and ':' between key and value
console.log(querystring.parse('name:Ravi;age:21', ';', ':').name);   // Ravi

// 4. escape and unescape
console.log(querystring.escape('a b&c'));         // a%20b%26c
console.log(querystring.unescape('a%20b%26c'));   // a b&c

Using it in a web server

JavaScript
const http = require('http');
const querystring = require('querystring');

http.createServer((req, res) => {
  const q = querystring.parse(req.url.split('?')[1] || '');
  res.end('Hello ' + (q.name || 'guest'));
}).listen(3000);
// http://localhost:3000/?name=Ravi  shows  Hello Ravi

Points to remember

  • All values come back as strings (age is '21', not 21).
  • If a key repeats, its values come back as an array.
  • querystring is an older (legacy) module; new code can also use URLSearchParams.

Write a note on URL module.

The url module is a built-in module that splits a web address into its parts (protocol, host, path, query and so on), so we can read each part easily. Node offers the modern URL class (recommended) and the older url.parse() method.

1. Modern way: the URL class

JavaScript
const myUrl = new URL('https://example.com:8080/students/list?year=2024&sem=3#top');

console.log(myUrl.protocol);                  // https:
console.log(myUrl.host);                      // example.com:8080
console.log(myUrl.hostname);                  // example.com
console.log(myUrl.port);                      // 8080
console.log(myUrl.pathname);                  // /students/list
console.log(myUrl.search);                    // ?year=2024&sem=3
console.log(myUrl.searchParams.get('year'));  // 2024
console.log(myUrl.hash);                      // #top

2. Older way: url.parse()

JavaScript
const url = require('url');
const q = url.parse('http://localhost:3000/default.htm?year=2024&month=march', true);

console.log(q.host);        // localhost:3000
console.log(q.pathname);    // /default.htm
console.log(q.search);      // ?year=2024&month=march
console.log(q.query.month); // march   (true = turn the query into an object)

Uses of the URL module

  • In a web server, read req.url to find which page (pathname) the user wants.
  • Read form values sent in the query string.
  • Build URLs from parts with url.format() or by setting properties of a URL object.

So the URL module saves us from cutting the address string by hand and makes routing and reading data simple.

How to read content in file ? Explain with example.

The fs (file system) module gives several ways to read a file:

  1. fs.readFile() – asynchronous, with a callback. Best choice in most programs.
  2. fs.readFileSync() – synchronous; Node waits until the file is read.
  3. fs.promises.readFile() – asynchronous, used with async / await.
  4. fs.createReadStream() – reads big files in small pieces (chunks).

Syntax: fs.readFile(path, encoding, callback(err, data)). If we do not give the encoding 'utf8', data comes back as a Buffer (raw bytes) instead of text.

Example

Suppose data.txt contains the line Hello from the file!

JavaScript
const fs = require('fs');

// 1. Asynchronous read
fs.readFile('data.txt', 'utf8', (err, data) => {
  if (err) return console.log('Error:', err.message);
  console.log('Async:', data);
});

// 2. Synchronous read
const text = fs.readFileSync('data.txt', 'utf8');
console.log('Sync:', text);
Output
Sync: Hello from the file!
Async: Hello from the file!

The sync line prints first, because the async callback runs only after the file has been read in the background.

With async / await

JavaScript
const fsp = require('fs').promises;

async function show() {
  try {
    const data = await fsp.readFile('data.txt', 'utf8');
    console.log(data);
  } catch (err) {
    console.log('Error:', err.message);
  }
}
show();

For a large file: stream

JavaScript
const stream = fs.createReadStream('big.log', 'utf8');
stream.on('data', (chunk) => console.log('Got', chunk.length, 'characters'));
stream.on('end', () => console.log('Finished reading'));

Points to remember

  • Always handle the error; a missing file gives the error code ENOENT.
  • Use 'utf8' to get text instead of a Buffer.
  • In servers, prefer the asynchronous methods so other users are not kept waiting.

Write a code to handle http request for Web Server.

A web server receives a request from the browser and sends back a response. Node's built-in http module lets us build one and decide what to send for each URL.

JavaScript
const http = require('http');

const server = http.createServer((req, res) => {
  console.log(req.method, req.url);                     // log every request

  if (req.method === 'GET' && req.url === '/') {
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end('<h1>Home Page</h1>');

  } else if (req.method === 'GET' && req.url === '/about') {
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end('<h1>About Us</h1>');

  } else if (req.method === 'GET' && req.url === '/api/students') {
    res.writeHead(200, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify([{ id: 1, name: 'Riya' }, { id: 2, name: 'Aman' }]));

  } else if (req.method === 'POST' && req.url === '/submit') {
    let body = '';
    req.on('data', (chunk) => body += chunk);           // collect sent data
    req.on('end', () => {
      res.writeHead(200, { 'Content-Type': 'text/plain' });
      res.end('Received: ' + body);
    });

  } else {
    res.writeHead(404, { 'Content-Type': 'text/html' });
    res.end('<h1>404 - Page not found</h1>');
  }
});

server.listen(3000, () => console.log('Server running at http://localhost:3000'));

How it works

  • require('http') loads the built-in module.
  • http.createServer(callback) creates the server. The callback runs for every request and gets two objects: req (the request: url, method, headers) and res (the response we send).
  • res.writeHead(status, headers) sets the status code (200 OK, 404 Not Found) and the content type.
  • res.end(data) sends the data and finishes the response.
  • req.on('data') and req.on('end') collect the body of a POST request.
  • server.listen(3000) starts the server on port 3000.
URL in browser Response
http://localhost:3000/ Home Page
http://localhost:3000/about About Us
http://localhost:3000/api/students JSON list of students
http://localhost:3000/xyz 404 - Page not found

What is synchronous call ?

A synchronous call runs one task at a time, in order. Each line waits for the line before it to finish, so a slow task (like reading a big file) blocks the whole program until it is done.

JavaScript
const fs = require('fs');
console.log('Start');

console.log(data);
console.log('End');

The output is always in this order: Start, the file content, End.

Explain event loop.

The event loop is what lets Node.js do non-blocking work on a single thread. It keeps checking: when the main code (the call stack) is empty, it takes the next ready callback (a finished timer, file read or network reply) from the queue and runs it. This repeats as long as there is work.

Its phases run in order: timers → pending callbacks → poll (I/O) → check (setImmediate) → close callbacks.

JavaScript
console.log('A');
setTimeout(() => console.log('B'), 0);
console.log('C');
// Output: A C B

B comes last because its callback waits in the queue until the main code has finished.

Explain Extend EventEmitter Class.

We can make our own class that extends EventEmitter. The new class gets all the event methods (on, emit, once), so its objects can raise their own events. Many Node objects, such as the HTTP server and streams, work this way.

JavaScript
const EventEmitter = require('events');

class School extends EventEmitter {
  admit(student) {
    console.log(`Admitting ${student}...`);
    this.emit('admitted', student);            // raise our own event
  }
}

const school = new School();
school.on('admitted', (name) => console.log(`Welcome email sent to ${name}`));
school.admit('Neha');
Output
Admitting Neha...
Welcome email sent to Neha

If the class has its own constructor, it must call super() first. Older code did the same with util.inherits(School, EventEmitter).

Write a code to create emp table with the fields eno and ename and insert five records.

Before running: start the MySQL server, create a database named company, and install the driver with npm install mysql.

JavaScript
const mysql = require('mysql');

const con = mysql.createConnection({
  host: 'localhost',
  user: 'root',
  password: '',
  database: 'company'
});

con.connect((err) => {
  if (err) throw err;
  console.log('Connected to MySQL');

  // 1. Create the table
  const createSql = 'CREATE TABLE emp (eno INT PRIMARY KEY, ename VARCHAR(50))';
  con.query(createSql, (err) => {
    if (err) throw err;
    console.log('Table emp created');

    // 2. Insert five records with one query
    const insertSql = 'INSERT INTO emp (eno, ename) VALUES ?';
    const values = [
      [1, 'Riya'],
      [2, 'Aman'],
      [3, 'Neha'],
      [4, 'Karan'],
      [5, 'Pooja']
    ];
    con.query(insertSql, [values], (err, result) => {
      if (err) throw err;
      console.log('Records inserted:', result.affectedRows);
      con.end();                                    // close the connection
    });
  });
});
Output
Connected to MySQL
Table emp created
Records inserted: 5

How it works

  1. mysql.createConnection() stores the server details: host, user, password and database.
  2. con.connect() opens the connection.
  3. con.query() runs any SQL command. The first query creates the emp table with eno (number, primary key) and ename (text).
  4. VALUES ? with the nested array [values] inserts all five rows in one query.
  5. result.affectedRows tells how many rows were added, and con.end() closes the connection.

Tip: With MySQL 8, if you get an authentication error, install mysql2 and write require('mysql2'). The rest of the code stays the same.

Way 2: show the records on a web page

JavaScript
const http = require('http');

http.createServer((req, res) => {
  con.query('SELECT * FROM emp', (err, rows) => {
    if (err) { res.end('Database error'); return; }

    let html = '<h2>Employee List</h2><table border="1"><tr><th>Eno</th><th>Ename</th></tr>';
    rows.forEach((r) => {
      html += `<tr><td>${r.eno}</td><td>${r.ename}</td></tr>`;
    });
    html += '</table>';

    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end(html);
  });
}).listen(3000, () => console.log('Open http://localhost:3000'));

(Here con is the same connection created above, without calling con.end().)

Points to remember

  • The callback gets (err, rows, fields): rows holds the data and fields holds column details.
  • To show one record, use a placeholder: con.query('SELECT * FROM emp WHERE eno = ?', [3], callback).
  • console.table(rows) prints the same records as a neat table.

Explain file upload.

File upload means sending a file (photo, PDF) from the user's computer to the server through a form. The form must use method="post" and enctype="multipart/form-data". Express cannot read such forms by itself, so we use the multer middleware, which saves the file and puts its details in req.file.

How to manage cookie ? Explain.

Managing cookies means setting, reading and deleting them. To read cookies easily, we use the cookie-parser middleware (npm install cookie-parser).

  • Set: res.cookie(name, value, options). Useful options: maxAge (life in milliseconds), httpOnly (JavaScript in the page cannot read it, which is safer), secure (sent only over HTTPS).
  • Read: req.cookies.name
  • Delete: res.clearCookie(name)
JavaScript
const express = require('express');
const cookieParser = require('cookie-parser');
const app = express();
app.use(cookieParser());

app.get('/set', (req, res) => {
  res.cookie('username', 'Riya', { maxAge: 24 * 60 * 60 * 1000, httpOnly: true });   // 1 day
  res.send('Cookie saved');
});

app.get('/get', (req, res) => {
  res.send('Hello ' + (req.cookies.username || 'guest'));
});

app.get('/clear', (req, res) => {
  res.clearCookie('username');
  res.send('Cookie deleted');
});

app.listen(3000);

Visiting /set and then /get shows Hello Riya. After /clear, /get shows Hello guest.

Write a note on route parameters.

Route parameters are named parts of a URL path that capture values. We write them with a colon, like /students/:id, and read the values from req.params.

JavaScript
app.get('/students/:id', (req, res) => {
  res.send('Student ID: ' + req.params.id);
});

app.get('/students/:sid/marks/:subject', (req, res) => {
  const { sid, subject } = req.params;
  res.send(`Marks of student ${sid} in ${subject}`);
});
URL req.params Response
/students/25 { id: '25' } Student ID: 25
/students/7/marks/maths { sid: '7', subject: 'maths' } Marks of student 7 in maths
  • Values are always strings; use Number(req.params.id) to get a number.
  • Route parameters identify which item (/students/25); a query string is used for optional filters (/students?sort=name).

Explain : how to send static file ?

Static files are files sent to the browser exactly as they are, without any processing: HTML pages, CSS, client-side JavaScript, images and PDFs. Express gives two ways to send them.

Way 1: express.static() – serve a whole folder

Folder structure
project/
├── app.js
└── public/
    ├── index.html
    ├── css/style.css
    └── images/logo.png
JavaScript
const express = require('express');
const path = require('path');
const app = express();

app.use(express.static(path.join(__dirname, 'public')));

app.listen(3000, () => console.log('Running on http://localhost:3000'));

Now these URLs work (the folder name public is not part of the URL):

  • http://localhost:3000/ shows index.html automatically
  • http://localhost:3000/css/style.css
  • http://localhost:3000/images/logo.png

To add a prefix, write app.use('/static', express.static('public')); then the URL becomes /static/css/style.css.

Way 2: res.sendFile() – send one particular file

JavaScript
app.get('/about', (req, res) => {
  res.sendFile(path.join(__dirname, 'views', 'about.html'));
});

res.sendFile() needs an absolute path, so we build it with path.join(__dirname, ...). To make the browser download a file instead of showing it, use res.download('files/report.pdf').

Point express.static() res.sendFile()
Sends Every file in a folder One file chosen in a route
Where written app.use() middleware Inside a route handler
Best for CSS, images, scripts A page for a specific URL

In both ways Express sets the correct Content-Type from the file extension, and sends 404 if the file does not exist.

List out request object methods and explain any three.

The request object (req) holds everything about the request the browser sent: the URL, method, headers and data. It is the first parameter of a route handler.

Property / method What it gives
req.params Route parameters, like id in /user/:id
req.query Query string values, like ?page=2
req.body Data sent by a form or as JSON (POST)
req.cookies Cookies (with cookie-parser)
req.method The HTTP method: GET, POST and so on
req.url / req.path The requested URL / path
req.ip / req.hostname The client's IP address / the host name
req.get('header') The value of a request header
req.is('json') Checks the type of data sent

1. req.params

Holds the values of route parameters. For the route /user/:id and the URL /user/15, req.params.id is '15'.

2. req.query

Holds the values from the query string (after ?). For /search?q=node&page=2, req.query.q is 'node' and req.query.page is '2'.

3. req.body

Holds the data sent in the body of a POST or PUT request, such as a login form. We must first add the body-reading middleware express.json() and express.urlencoded().

JavaScript
const express = require('express');
const app = express();
app.use(express.json());                           // read JSON body
app.use(express.urlencoded({ extended: true }));   // read HTML form body

app.get('/user/:id', (req, res) => {                // req.params
  res.send('User id: ' + req.params.id);
});

app.get('/search', (req, res) => {                  // req.query
  res.send(`Searching "${req.query.q}", page ${req.query.page}`);
});

app.post('/login', (req, res) => {                  // req.body
  res.send('Welcome ' + req.body.username);
});

app.get('/info', (req, res) => {                    // req.get()
  res.send('Your browser: ' + req.get('User-Agent'));
});

app.listen(3000);
Request Output
GET /user/15 User id: 15
GET /search?q=node&page=2 Searching "node", page 2
POST /login with username=Riya Welcome Riya
